## Reconstruction actually performed

An initially clean **detached worktree** was created at the pinned base using existing local Git objects. No new clone, fetch, branch or commit was used for that check. HEAD was verified and status was empty before applying anything.

1. `git apply --check --whitespace=error-all` accepted the patch.
2. `git apply --whitespace=error-all` reconstructed the eight files.
3. Bundle verification with `--source` matched their normalized bytes, with exactly the eight expected untracked files and no tracked changes.
4. A second application check failed with `already exists in working directory` for all eight additions. No force or three-way application was used; verification confirmed the refusal changed no payload.
5. The reconstructed tree passed the nine focused suites listed below. In the same test process, all three preview modules' `__file__` paths were asserted to be exactly inside that tree, not the editable source checkout.

## Unrun tiers and limitations

- The full upstream unit suite stopped during collection on Windows **before the preview implementation**: `tests/test_nightly_ledger.py` and `tests/test_sim_generator.py` reach the Unix-only `resource` import in `tools/sim_harness/replay.py`. No skip or portability patch was added to conceal this blocker.
- No fresh clone/dependency environment, full Linux/WSL run, real-HA tier, live equipment, production-engine simulator or household study is established by this record.
- The original browser demo is independent of the contribution. Its earlier smoke check is described in the [test guide](../../docs/TEST_PLAN.md); no new browser validation accompanies this snapshot.
- Synthetic mode revisions/readiness are not real Home Assistant ownership detection, device-safety validation or physical restoration. Local-time resolution is not a recurring scheduler.
- Existing upstream default automation, manual-grace, startup and persistent-hold policies remain unchanged and are not validated as satisfying this project's proposed control requirements.
- No measured comfort improvement, sleep benefit, energy savings or hardware-safety result is claimed. The modules remain disconnected from production paths.

If the payload changes, regenerate deliberately, repeat reconstruction and update this evidence. Review integrity, licensing, integration behavior and actual device safety as separate questions rather than treating a matching hash or passing unit suite as an all-purpose approval.
